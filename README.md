# Restaurant Management System

A C# desktop application built to understand and practice multi-threading concepts through a restaurant simulation game.

## About

This project simulates a restaurant management system where multiple operations run simultaneously using threads, demonstrating real-world concurrent programming scenarios.

## Features

- Multi-threaded restaurant operations
- Desktop-based game interface

## Technologies

- C#
- Windows Forms / WPF
- Multi-threading (Thread management)

## Purpose

Built as a learning project to understand and master thread management and concurrent programming in C#.
